# 学习方法 · 四年级上册
#
# 目的：教她**自己面对难题**。主线是五步 ——
#     🎯 想要什么 → 🔎 收集信息 → 🧠 分析问题 → ✋ 解决问题 → 🔁 检查复盘
# 园地二那句「博学之，审问之，慎思之，明辨之，笃行之」就是这条主线，课本里现成的。
# 底下想让她慢慢明白的：专心、不应付、想清楚自己要什么、想到就去做、不怕 ——
# **只藏在常识和用法里，页面上一句都不直接说**（见下「口吻」）。
#
# 一课提炼一个方法，名字借那一课（田忌法、庐山法……）—— 课文她天天在学，名字一叫
# 就知道说的是什么，不用大人再讲道理。三科共用：英语朗读卡在长词上是「田忌法」，
# 数学应用题读岔了是「王戎法」，名字不变才会潜移默化。
#
# 两个下游：
#     语文 · 学习方法（dist/chinese/methods/）   一课一张卡，**严格照课本顺序**
#     英语打卡评价的「下次读之前」               报告里只写方法名，图标和问句从这儿取
#
# ── 格式 ──────────────────────────────────────────────────────────
#     [单元] 第一单元 | 单元页上那句话
#     [方法名] <课号> <课名> | 问自己的那一句 icon=<图标> step=<五步之一> use=<作业里怎么用>
#         课 课文里那件事，一句话（照课文写，别凭印象）
#         理 常识名 | 哪一类 | 讲给孩子的话，用 // 分块（不要一整段）：
#               第一块 = 这是什么；「例：」开头 = 课文里的例子、「实验：」开头 = 研究里的实验
#               （页面上各进一个小框）；最后一块不是框的话 = 落点，前面带 →
#         用 课本里的一句 ——朝代·人名《作品》 → 遇到问题时怎么用   （可多条，语文园地用得最多）
#           作者和出处印在左边那句下面另起一行、靠右；右边只讲怎么用，别再写「韩愈说：」
#           「这是《师说》里的话」。作品名拿不准就只写作者，别猜
#
# **区块顺序就是课本顺序**：课文照课次，语文园地排在本单元最后一课后面，
# 第五单元是习作单元、放「交流平台」。语文园地和课文一样是一张卡（课号那格写
# 「语文园地二」），**园地里的东西一样都不漏**：梳理与交流进「课」、名言警句 /
# 日积月累 / 书写提示 / 单元页那句话都进「用」—— 不列原文，写**遇到问题时怎么用**。
# 识字加油站、词句段运用是语言练习，不收。
#
# 「理」是右半张卡：方法论 / 辩证法 / 哲学 / 心理学的常识，一课一个、不重复。
# **要接得上这一课**（女娲担心天再塌就先撑住 = 墨菲定律），接不上的宁可换一个。
#
# **口吻：平等地分享知识，不说教。** 页面上不出现「应该 / 别 / 吃亏的是自己」这类话 ——
# 那是大人在下判断，她一眼就读得出来。讲谁发现的、做过什么实验、这招怎么用，
# 让她觉得「赚到了」。话要孩子懂，内容要专业、准确（人名、实验、结论都得对）。
# 走神 / 应付 / 想清楚要什么 / 别怕这些意思，藏在常识里（选择性注意、心流、
# 内驱力、第一性原理、勇气、聚光灯效应……），不直接说出来。
#
# step= 只是卡片上的小标签，不决定顺序。
#

[单元] 第一单元 | 江流天地外，山色有无中。——唐·王维《汉江临泛》

[观潮法] 1 观潮 | 先发生什么，后发生什么？ icon=🌊 step=收集信息 use=应用题按事情先后，把条件排一排
    课 潮来前江面风平浪静，潮来时白线变成水墙，潮过后余波还在涌来
    理 现象与本质 | 辩证法 | 看得见的叫「现象」，藏在后面的原因叫「本质」。 // 例：钱塘江大潮为什么这么大？资料袋揭了底：杭州湾外宽内窄像个喇叭，潮水越往里挤越高。 // 找到本质，下一次就能猜到会发生什么。

[繁星法] 2 繁星 | 换个地方，还一样吗？ icon=✨ step=分析问题 use=同一类题换了数字，想想做法变不变
    课 巴金在家乡、南京、海上看星星，每一回感受都不一样
    理 具体问题具体分析 | 辩证法 | 地方、时候、条件一变，好办法也跟着变 —— 哲学里管这叫「具体问题具体分析」。 // 例：同样的星星，巴金在家乡、南京、海上看出了三种感觉。 // 先看这一次有什么不一样，再动手。

[花牛法] 3 花牛歌 | 脑子里能画出来吗？ icon=🐄 step=收集信息 use=应用题先画线段图；读课文先想画面
    课 花牛在草地里坐、眠、走、做梦，一句就是一个画面
    理 双重编码 | 心理学 | 心理学家佩维奥发现，脑子里有两个仓库：一个存文字，一个存画面。 // 同一样东西两个仓库都存上，就特别难忘。 // 线段图、脑子里的画面，用的都是第二个仓库。

[五感法] 语文园地一 | 能看到、听到、闻到吗？ icon=👃 step=收集信息 use=读题、读课文时，把描写变成画面和声音
    课 读《繁星》像看到满天繁星，读《观潮》像听到震耳欲聋的潮声，读文章还能「闻」到味道
    理 习惯的力量 | 心理学 | 一件事重复多了，大脑会把它交给「自动驾驶」，做起来一点不费劲。 // 例：书法家提笔就写得好，是因为认真早就变成了自动的。
    用 书写提示：字的中心落在中线上、字距差不多 → 一行字这样写，看着就齐整，回头检查也省眼睛
    用 书写提示：认真对待每次写字，养成提笔就练字的习惯 → 每写一次字都算一次练习，一年下来就是几千次
    用 一年好景君须记，最是橙黄橘绿时 ——宋·苏轼《赠刘景文》 → 荷叶没了、菊花也残了，苏轼偏说一年最好的是橙黄橘绿的时候 —— 换个角度，看着不好的时候也藏着好东西
    用 江流天地外，山色有无中 ——唐·王维《汉江临泛》 → 王维看江看山，近的远的都收进眼里 —— 看题也可以先远看整体、再近看细节

[单元] 第二单元 | 为学患无疑，疑则有进。——宋·陆九渊

[豌豆法] 4 一个豆荚里的五粒豆 | 我有什么问题？ icon=🌱 step=收集信息 use=读完一篇课文，先说一个自己的问题
    课 读完五粒豌豆的故事，同学们写下问题：掉进水沟的那一粒真是最了不起的吗？
    理 苏格拉底提问法 | 哲学 | 两千多年前，古希腊的苏格拉底教学生从来不给答案，只是一个接一个地问。 // 问着问着，学生自己就想明白了。 // 一个好问题，常常比一个答案更值钱。

[蝙蝠法] 5 夜间飞行的秘密 | 一次只试一样，是哪个管用？ icon=🦇 step=分析问题 use=算错了找原因：一次只换一个地方重算
    课 科学家蒙上蝙蝠的眼睛、塞上耳朵、封住嘴，各试一次，才知道它靠嘴和耳朵探路
    理 控制变量法 | 科学方法 | 想知道是哪个原因，就一次只改一样，其余的都不动。 // 例：蒙眼、塞耳、封嘴，科学家一次只试一样，才找到蝙蝠靠的是嘴和耳朵。 // 今天试新药、改飞机，用的还是这一招。

[方帽子法] 6 方帽子店 | 哪个问题最要紧？ icon=🎩 step=分析问题 use=错题多的时候，先改最常错的那一类
    课 问题一大堆：「呢绒帽是什么」不影响读懂，「方帽子店为什么失败」才值得想
    理 二八定律 | 经济学 | 意大利经济学家帕累托发现：很多事情里，大约八成的结果来自两成的原因。 // 错题也常常这样 —— 找到那两成，最省力。

[田忌法] 7 田忌赛马 | 换个顺序行不行？ icon=🐎 step=解决问题 use=难词先单独念熟，再放回句子里读
    课 一匹马也不换，只换出场的顺序，田忌就赢了齐威王
    理 整体与部分 | 辩证法 | 系统科学里有句话：整体不等于部分简单相加。 // 例：田忌的马一匹没换，只换了出场顺序，输家就变成了赢家。 // 同样的东西，换个组合，结果能完全不同。

[审问法] 语文园地二 | 我问到点子上了吗？ icon=❓ step=收集信息 use=卡住时先说出「我不懂的是哪儿」
    课 大胆提问，从不同角度提问，再筛出值得想的问题，养成敢问、会问的习惯
    理 批判性思维 | 思维方法 | 科学家、侦探、法官有一个共同的习惯：听到一个说法，先问三句。 // 真的吗？证据呢？还有别的可能吗？ // 这三句能挡住很多错误。
    用 博学之，审问之，慎思之，明辨之，笃行之 ——《中庸》 → 两千多年前就有人把解难题分成了五步：多了解、问清楚、仔细想、分对错、去做
    用 智能之士，不学不成，不问不知 ——东汉·王充《论衡》 → 再聪明的人，不学也成不了，不问也不知道
    用 人非生而知之者，孰能无惑 ——唐·韩愈《师说》 → 没有人生下来就什么都懂，有了疑惑就去问
    用 善疑者，不疑人之所疑，而疑人之所不疑 ——明·方以智 → 会提问的人，专挑大家都觉得没问题的地方问 —— 很多发现就是这么来的
    用 为学患无疑，疑则有进 ——宋·陆九渊 → 读书最怕没有疑问；冒出一个疑问，就是要往前走一步了

[庐山法] 8 题西林壁 | 跳出来看，是什么样？ icon=⛰️ step=检查复盘 use=写完放一放再检查；听自己的录音
    课 横看成岭侧成峰 —— 不识庐山真面目，只缘身在此山中
    理 元认知 | 心理学 | 「元认知」就是站到自己的脑子外面，看看自己是怎么想的 —— 就像走出庐山再看庐山。 // 心理学研究发现，学得好的人，往往很会这一招。

[爬山虎法] 9 爬山虎的脚 | 凑近看，看仔细了吗？ icon=🌿 step=收集信息 use=形近字凑近看清每一笔
    课 以前只知道它叫爬山虎，今年一留心，才发现爬山虎是有脚的
    理 选择性注意 | 心理学 | 注意力像手电筒，照到哪儿才看见哪儿。 // 实验：让人专心数篮球传了几次，一半的人没看见中间走过去的「大猩猩」。 // 叶圣陶这一年把手电筒照向了爬山虎，才看见它的脚。

[蟋蟀法] 10 蟋蟀的住宅 | 多看几回，有变化吗？ icon=🦗 step=收集信息 use=同一类错连着记几天，看是不是少了
    课 法布尔一连看了两个钟头，从秋天一直看到冬天
    理 量变到质变 | 辩证法 | 水一度一度地烧，到了一百度，一下子变成水汽 —— 哲学里管这叫「量变到质变」。 // 例：蟋蟀今天挖一点、明天挖一点，最后挖成了「伟大的工程」。

[留心法] 语文园地三 | 眼睛、耳朵、脑子都用上了吗？ icon=👀 step=收集信息 use=做题前先把题目读两遍，圈出条件
    课 细致观察才能写得准确；连续观察一段时间，发现变化；不光用眼睛看，还要用耳朵听、用心想
    理 归纳法 | 逻辑 | 把很多次看到的放在一起，找出一样的地方，就得到了规律 —— 这叫「归纳」。 // 例：「一场秋雨一场寒」就是古人看了很多年天气，归纳出来的。
    用 立了秋，把扇丢；一场秋雨一场寒（园地三的六条气象谚语）→ 古人看了很多年天气总结出来的，比天气预报早了一千多年
    用 处处留心皆学问 → 学问不只在书里，墙上的爬山虎、草地上的蟋蟀，都藏着

[盘古法] 11 盘古开天地 | 下一步是什么？ icon=🪓 step=解决问题 use=解题一步写一行，一步接一步
    课 醒来、劈开「大鸡蛋」、顶天立地、身体化成万物，一步接着一步
    理 分而治之 | 方法论 | 计算机科学家碰到超大的问题，先把它切成许多小问题，一个一个解决，这叫「分而治之」。 // 例：盘古开天地，醒来、劈开、顶天、化万物，也是一步接一步来的。

[精卫法] 12 精卫填海 | 难，也接着做？ icon=🐦 step=解决问题 use=背不下来就每天背一小段
    课 精卫常常衔着西山的树枝和石子，去填东海
    理 坚毅 | 心理学 | 心理学家达克沃斯研究了很多把事做成的人，发现除了聪明，还有一样东西很要紧，她叫它「坚毅」。 // 就是认准一个目标，一直不放手。

[普罗米修斯法] 13 普罗米修斯 | 起因、经过、结果是什么？ icon=🔥 step=分析问题 use=复述故事、读长题，都先理出起因、经过、结果
    课 人间没有火 → 他从天上取来火种，被锁在悬崖上 → 大力士射死鹫鹰，救了他
    理 因果联系 | 辩证法 | 世界上的事一件连着一件：前一件是「因」，后一件是「果」。 // 把因果串起来，就能顺着链子往回找，看问题出在哪一环。

[女娲法] 14 女娲补天 | 还缺哪一块？ icon=🧩 step=检查复盘 use=做完对着题目一条一条查，有没有漏
    课 补天、撑天、杀黑龙、堵地缝，一处一处都补好了
    理 墨菲定律 | 常识 | 工程师墨菲说过一句很有名的话：可能出错的地方，迟早会出错。 // 例：女娲补好了天，还担心它再塌下来，又把天撑住。 // 所以做完事，先去看最容易出错的地方。

[猜想法] 语文园地四 | 能先猜一个答案吗？ icon=💭 step=分析问题 use=不会的题先猜一个答案，再代进去验一验
    课 古人不知道火从哪里来，就想出普罗米修斯「盗」火种的故事来解释；神话充满神奇的想象
    理 假设与验证 | 科学方法 | 古人用神话解释火从哪儿来，这叫「提出假设」。 // 科学家也这么做，只是多了一步：想办法去验证。 // 科学就是猜一个、验一个，这么走过来的。
    用 精卫坚韧执着、普罗米修斯勇敢不屈 → 卡住的时候可以问问自己：精卫会怎么做？普罗米修斯会怎么做？
    用 嫦娥应悔偷灵药 ——唐·李商隐《嫦娥》 → 李商隐猜嫦娥后悔了 —— 做决定前多想一步以后，就少一件后悔的事

[麻雀法] 15 麻雀 | 看到的、听到的、想到的，都说了吗？ icon=🐤 step=解决问题 use=写作文、讲一件事，把看到听到想到的都写上
    课 屠格涅夫把看到的、听到的、想到的都写下来，老麻雀救小麻雀的事就写清楚了
    理 勇气 | 心理学 | 心理学家说，害怕是大脑在喊「注意」，每个人都会有。 // 例：老麻雀浑身发抖，还是飞了下来。 // 勇敢不是不害怕，是害怕的时候也能迈出那一步。

[天都峰法] 16 爬天都峰 | 谁能跟我一起？ icon=🧗 step=解决问题 use=大人在旁边做自己的事，陪着她一起做
    课 「我」和老爷爷互相鼓劲，一起爬上了峰顶 —— 都会从别人身上汲取力量
    理 薛定谔的猫 | 物理学 | 物理学家薛定谔设想过一只关在盒子里的猫：不打开盒子，谁也说不清它怎么样了。 // 例：站在山脚想「我爬得上去吗」，也是一只没打开的盒子。 // 打开它的办法只有一个：去爬。

[六要素法] 交流平台 | 时间、地点、人物、起因、经过、结果，都说了吗？ icon=📝 step=解决问题 use=讲一件事前，先在心里过一遍六要素
    课 写清楚一件事：交代时间、地点、人物，按一定顺序写起因、经过、结果
    理 5W1H | 方法论 | 记者写新闻，心里都有一张清单。 // 何时、何地、何人、何事、为何、如何。 // 六个问题问全了，一件事就清清楚楚。
    用 按爬山前、爬山中、爬上峰顶后的顺序写 → 做事也分前、中、后：做之前想一想，做的时候专心，做完回头看一眼
    用 把看到的、听到的、想到的都写下来 → 说不清楚的时候，把这三样分开说，一下就清楚了
    用 我手写我心 → 写自己真看到、真想到的，文章才有意思
