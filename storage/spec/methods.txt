# 方法工具箱
#
# 遇到难处时用的几个办法，**每个都借语文课本里的一课起名字** —— 课文她天天在学，
# 名字一叫就知道说的是什么，不用大人再讲一遍道理。三科共用同一份：英语朗读卡在
# 长词上是「田忌法」，数学应用题读岔了也是「王戎法」，名字不变才会潜移默化。
#
# 一个区块一个方法：
#     [方法名] <课号> <课名> | 问自己的那一句       ← 报告里印成「语文第 7 课《田忌赛马》」
#     （一课几首诗的，课名写那一首：8 题西林壁）
#         缩进行：课文里那件事，一句话（报告里印在方法名下面）
#
# ⚠️ **只用她已经学过的课。** 没学过的课，名字对她没意义 —— 那就又变成大人在讲道理。
#    这份表可以先写着，用之前对一下语文进度（写字单 / 抽查单做到哪一课）。
#    2026-09-23 学完第二单元（第 1~7 课 + 园地一、二），第 8 课起还没学。
#    第 8 课起的那几条，缩进行是凭印象写的，**轮到用之前拿课本核一遍**。
#
# 挑方法的口径：从教材总览里 ★★★ 的那几课挑，**一件事一个办法**，
# 两个方法说的是同一件事就只留一个。要加一个先想清楚它和现有的有什么不同。

[田忌法] 7 田忌赛马 | 换个顺序行不行？
    同样三匹马，换个出场顺序，输的就变成了赢的

[庐山法] 8 题西林壁 | 跳出来看，是什么样？
    不识庐山真面目，只缘身在此山中 —— 站在山里看不清山，走出来才看得清

[天都峰法] 16 爬天都峰 | 能拆成一小步一小步吗？
    那么高的山，一级一级台阶往上爬，就爬上去了

[牛和鹅法] 20 牛和鹅 | 我原来的想法要改吗？
    原来怕牛不怕鹅，被鹅追过一回、听了金奎叔的话，才换了个看法

[陀螺法] 22 陀螺 | 第一眼看到的对吗？
    最不起眼的那只小陀螺，转得比谁都久

[王戎法] 23 王戎不取道旁李 | 我的证据是什么？
    路边的李子树结满了果子没人摘，王戎就知道李子一定是苦的
