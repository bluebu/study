# 放学第一件事：把作业本摊开，照着这张单子从上往下过一遍。
# 每天一张，打印一叠放书桌上。
#
# **一个区块 = 纸上一栏**，两种行混着写都行：
#   缩进行  = 说明（每条前面一个圈，过一条画一个）
#   项行    = 一项作业类型（`,` `，` `、` 分隔，可跨行），每项两个格：今天留了 ｜ 已完成
#   lines=N = 这一栏留 N 行横线（要写整段话的栏才用；三科各项自带横线）
#   （项怎么排不用管：一律 5 个一组、排 2 列，不足 5 个整组留在左列）
#
# **项的顺序就是做的顺序**，纸上自动编号 —— 预习、复习优先级靠后，排在末尾。
# 改顺序只动下面的项行，别去动代码。
# 第一栏纸上会上底色 —— 顺序就是检查顺序，别把「抄下来了吗」挪到后面去。
