# 笔画名 —— 机器给的名字里，哪些要人来定
# 字形数据（storage/data/chinese/stroke-names.json）是原样存下来的，里面有两种
# **不能直接印在纸上**的名字，判断落在这份表里：
#
#   1. 一码两名（`横撇|横钩`）—— 同一个笔画码在不同字里是两种笔画，得看字形
#   2. 内部标记（`点2`）—— 那是数据自己用的代号，不是笔画的正式名称
#
# 生成器的取名次序：[按字] → [默认名] → 数据里的 name。
# **名字里带 `|` 或带数字的，两处都没给就当场报错** —— 印一个「点2」到纸上，
# 孩子会当成一种笔画的名字记住。

[默认名]
# d：数据里叫「点2」，shape 给的却是 ㇀（提）。实测这批三处都是「宀 / 冖 / 雨字头」
#    的那一点（综第 5 笔、蕾第 5 笔、棠第 4 笔），规范写法就是「点」。
d=点,
# e：横撇 和 横钩 共用一个码。这批三处都是宀 / 冖 / 雨字头收尾那一笔 —— 横钩。
#    真遇到「横撇」（比如「又」「水」里那种），在 [按字] 里按字覆盖。
e=横钩,
# w：横折折折钩（乃、及那一笔）和 横撇弯钩（耳刀旁 阝）共用一个码。
#    这批两处正好一边一个，所以默认取「锈」那个，「部」在下面按字覆盖。
w=横折折折钩

[按字]
# 「字.笔序」= 名字。笔序从 1 数起，和纸上印的号码一致。
# 部的第 9 笔是右耳旁「阝」的第一笔 —— 横撇弯钩，不是乃字那种横折折折钩。
部.9=横撇弯钩
