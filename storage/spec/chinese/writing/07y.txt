# 语文园地二 词语表 · 笔顺
# 来源：课本末尾**词语表**里「语文园地二」那一组（用户拍的照片），8 个词 17 个字。
#   不是写字表 —— 词语表只要求会认会写词，这张单子练的是每个字怎么一笔一笔写下来。
# 命名照抽查单那套：园地二 = `07y`（第二单元最后一课是第 7 课，园地排在它后面）。
#
# **不增不删**：照片上 8 个词一个不落、顺序照抄，没自己补组词和造句。
#
# 拼音按**词语语境**定音，多音字只有一处要判断：
#   乐 —— 俱乐部读 lè，不是 yuè（「乐」作「快乐」义时 lè，作「音乐」义时 yuè）
#   其余 16 字都是单音字，pypinyin 的自动补全在这种情况下可信，但仍旧写进 spec ——
#   这个栏目的纸是照着写的，拼音错一个孩子就读错一个。
# 「结」在别处有 jiē（结实、结巴），结账是 jié。「泡」在别处有 pāo（泡桐、尿泡），泡沫是 pào。
