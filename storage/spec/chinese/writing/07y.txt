# 来源：课本末尾的**写字表**和**词语表**里「语文园地二」那两组（用户拍的两张照片）。
#   每课都分成写字表 / 词语表两部分，**写字表在前、词语表在后**，这张单子照这个顺序排。
#   两组都要求**会默写**，所以两个区块都挂 copy=1（抬头后面出徽章）。
# 命名照抽查单那套：园地二 = `07y`（第二单元最后一课是第 7 课，园地排在它后面）。
#
# **不增不删**：照片上写字表 9 个字、词语表 8 个词，一个不落、顺序照抄，

#   但课本没这么给，所以**不并成词**，照单字排。
#
# 拼音按**词语语境**定音：
#   乐 —— 俱乐部读 lè，不是 yuè（作「快乐」义时 lè，作「音乐」义时 yuè）
#   结 —— 结账是 jié，不是 jiē（结实、结巴才读 jiē）
#   泡 —— 泡沫是 pào，不是 pāo（泡桐、尿泡才读 pāo）
#   写字表是单字，按字典的单字音：瑰 guī（「玫瑰」连读时第二个字轻声，
#   但单字条目是 guī，这张表练的是单字）
