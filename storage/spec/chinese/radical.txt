# 偏旁部首 —— 逐字归部，人定
# 部首是语文内容，**判断权在字典和课本，不在机器**。这份表是人写的，
# 机器（cnchar-radical）只能拿来出候选、不能直接用 —— 它把「玫」归到了「攵」，
# 而玫从玉、右边的攵只是声旁，规范归「王」部。一处错了就说明整批都得人核。
#
# 格式：`字=部首` 或 `字=部首|这个位置叫什么`。
# 给了第二段就用第二段当名字，没给就查 [部首名]。
# **同一个部首在不同位置名字不一样** —— 木在左边是木字旁、在底下是木字底，
# 所以「棠」得单写。
#
# ⚠️ 独体字没有偏旁可拆，部首就是它自己（生、气、丹、乐）。纸上照实印
# 「独体字」，别硬安一个偏旁名 —— 那是编的。

[部首名]

牜=牛字旁, 亻=单人旁, 阝=右耳旁, 艹=草字头, 王=王字旁, 十=十字头,
气=气字头, 人=人字头, 木=木字旁, 丿=撇, 生=生, 丶=点

# —— 词语表那 17 个字 ——
提=扌, 纲=纟, 锈=钅, 泡=氵, 沫=氵, 综=纟, 结=纟, 账=贝, 矿=石,
物=牜, 俱=亻, 部=阝, 氧=气,
# 「合」两说：《新华字典》归人部（合 = 亼 + 口，亼是人字头），
#   小学练习册里也常见归口部。这儿按字典写「人」—— 要改成口部，改这一行就行。
合=人,
# 独体字：自成一部，不拆偏旁
生=生|独体字, 气=气|独体字, 乐=丿|独体字,

# —— 写字表那 9 个字 ——
卉=十, 瑰=王, 牡=牜, 蕾=艹, 茉=艹, 莉=艹,
# 玫：机器给的是「攵」，**错**。玫从玉、文声，右边的攵是声旁，规范归王部。
玫=王,
# 棠 = 尚 + 木，上下结构，木在底下 —— 叫木字底，不是木字旁
棠=木|木字底,
丹=丿|独体字
