# kousuan：口算卷照片 → 错题清单 + 计算秘籍

```
口算卷照片 ──crop.py──► 转正 + 放大的分块图
                             │ 会话逐题抄成「题=孩子写的」
                             ▼
                        抄的.txt ──check.py──► 对错 · 统计 · 「多/少一个 0」线索
                             │ 会话归错因、挑同类题（换数）
                             ▼
             src/math/specs/<slug>.txt ──build.py──► 两页 A4 + 答案版
```

第 1 页「错在哪」：错题按错因分组 + 一组对照点破错在哪一步。
第 2 页「秘籍」：口诀卡 + 27 道同类题。答案版只出第 2 页。

先读根 `CLAUDE.md`（打印硬约定、发布策略）。两个脚本在本 skill 目录下，
临时文件（分块图、抄的 txt）一律丢 scratchpad，别落进仓库。

## 流程

1. **定方向**：`python3 .claude/skills/kousuan/crop.py 照片 -o <scratchpad>`
   出三张缩略图，Read 一张看哪个正。
2. **分块放大逐题抄**：`crop.py 照片 -o <scratchpad> --rot cw --blocks 3`，
   Read 每块，抄成一行一题的 `题=孩子写的`。
   **看不清就 `--zoom x1,y1,x2,y2 --scale 10` 单独放大**，别猜（坐标按转正后的 `full.jpg` 量）。
3. **判对错**：`python3 .claude/skills/kousuan/check.py 抄的.txt`。
   **正确率、错几题这些数字一律照抄它的输出，不要自己数**。
4. **归错因 → 写 spec**（`src/math/specs/<slug>.txt`，语法见下）：
   错题按错因分组，一组一句话；练习题挑同类型的，**必须换数字**。
5. **构建自检**：`python3 build.py --pdf`，然后 **Read 生成的 PDF 两页**
   （别凭 HTML 想象）。目标：第 1 页内容落在 2/3 页以上、第 2 页正好一页不溢出。
6. 自检过了直接 commit + push。

## 判卷口径

- **一位数字之差就是另一道题**：`0.07 / 0.97`、`14 / 140`、`2920 / 29200`
  在照片上极难分辨，凡是拿不准的都 `--zoom` 到 8–10 倍确认一遍再抄。
- 值对写法不规范（小数结果 `10.0` 该写 `10`）check.py 标 `~`，
  **不算错、不进错题清单**，最多在 tip 里提一句。
- 竖式草稿写在题边上，别把草稿数字当成答案抄。
- 抄不下来的（写得糊、擦改过）先问用户，别猜。

## 出单子的三条

- **练习题必须换数字**。第 1 页印着正确答案，第 2 页再出原题就是让孩子照抄。
- **练习题只写题面，答案脚本算**（`src/math/build.py` 的 `_answer`）。
  除法必须整除，除不尽会直接报错 —— 口算单不出这种题。
- **A4 上不写大段分析**。错因一组一句话，方法用图示（划掉的 0）讲，
  家长和孩子都不读长文。想说的展开话写在会话回复里，不要写进纸。

## spec 语法

```
# 除法里的 0                     ← 首个 # 行是卷名（第 2 页页头）
date: 8月27日
diag: 错在哪                     ← 第 1 页页头
score: 50 题　对 38　错 12　正确率 76%    ← 照抄 check.py 最后一行
tip: 12 题里 11 题错在同一件事 —— 0。秘籍在第 2 页
verify: 商 × 除数 = 被除数　　2×70=140 ✓　　20×70=1400 ✗

[示范]                           ← 口诀卡；<0> = 划掉这个字符，| 右边是注解
14<0>÷7<0> = 14÷7 = 2 | 两边一起划，划一样多

[对照] 这 9 题错在同一步          ← ✗ 开头的注解那行整行灰掉，✓ 那行是正解
140÷70 → 14÷7=2 → 把 140 的 0 抄回来 = 20 | ✗ 只划了被除数
14<0>÷7<0> → 14÷7 = 2 | ✓ 两边一起划

[错题] 只划了被除数的 0，商多一个 0 | 9 题     ← 抬头是错因，右标签是题数
140÷70, 20, 2                    ← 每行「题, 孩子写的, 正确的」

[① 两边一起划] 换了数，再做一遍    ← 练习题，逗号分隔，只写题面
320÷40, 280÷70, 450÷90
```

`[错题]` 可以有多组（一个错因一组，只有 1 题的组会自动并排放）。
练习题 3 列排版，**27 题（3 列 × 9 行）正好铺满第 2 页**，加减题量按这个基数调。
