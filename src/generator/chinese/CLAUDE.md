# 语文 · 项目准则

学习小站的语文科。搬内容进来之前先读这份。

## 教学体系：书上怎么写就怎么印

最高准则 —— 这一科的内容全部来自课本，**判断权在课本，不在经验**：

- **要求一律照课后题原话**：「有感情地朗读课文。背诵第 3~4 自然段。」就写这个，
  别发明「熟悉」「掌握」「熟读成诵」—— 书上根本没有这些词
- **课文原文一字不改**：标点、省略号、分段照课本抄
- **多音字按课文语境定音**：`单=dān` 不是 shàn、`悄悄=qiāo qiāo` 不是 qiǎo。
  脚本只排版、不判断读音，`pypinyin` 的自动补全只对单音字可信
- **背诵和默写是两件事**：书上要求背的不一定要默写。四上 1~14 课只有
  《题西林壁》写了「默写」，所以总表里这两样分两列、分开统计
- **课本没覆盖的写「待补」**，不猜、不从别的版本抄 —— 手上这份 2024 版电子课本
  只到书页 53（一~四单元）；2024 版和 2019 版课次编号不一样（《走月亮》2024 版
  已删，第 2 课是《繁星》），混用错得很隐蔽

用的是 2024 版人教统编版，当前进度四年级上册。

## ⚠️ 教材版本：2019 版和 2024 版差得很远，别混用

**每一条内容都要拿手上这本教材核过再进 spec。** 这不是理论风险 ——
抽查单最早那一批就是照 2019 版编的，错得很隐蔽：

- **第 6 课整课不同**：2019 版是《呼风唤雨的世纪》，2024 版是《方帽子店》
  （《呼风唤雨的世纪》在 2019 版是第 7 课）
- **写字表逐课都不一样**：第 1 课 2019 版 14 字（潮 据 堤 越…），
  2024 版 12 字（据 随 堤 顿…）。9 张抽查单的听写块全错
- **日积月累串位**：《别董大》2019 版在园地三，2024 版在**园地八**；
  园地三换成了 6 条气象谚语。园地二的 4 句名言也换了两句
- **课文里的词也改**：观潮「两丈多高的水墙」→「一堵高高的水墙」，
  结尾「江水已经涨了两丈」整句删掉；女娲「斩下」→「砍下」
- 第 20 课（牛和鹅）、24 课（我将无我，不负人民）是 2024 版新编进来的

**核对不靠肉眼，靠脚本**：

```bash
make textbook          # 默认核四上语文；PDF= 指别的教材
```

`tools/vs-textbook.py` 干三件事：抽查单「读准」「词语」两个区块里的词
必须在它那几页课文里（spec 文件头的 `pages:` 是课文书页）；教材总览的
`write=` 逐课相加必须等于书末写字表标的「共 250 个字」；书页→PDF 页的偏移
自己探。**它只报不改** —— 改哪个字是判断。

教材 PDF 是版权内容，**不进仓库**：本机 `~/workspace/personal/教材/` 下。

## 栏目

```
practice    今日练习 —— 看拼音写汉字 → A4 田字格练习单（附答案版）   ← 已上线
recite      背诵单 —— 要背的那段切成块，三轮撤提示 + 四天间隔打卡     ← 已上线
check       抽查单 —— 学完一课家长照着问 → 题面版 + 家长版           ← 已上线
overview    教材总览 —— 一册一份的总表，哪篇要背、哪首要默写         ← 已上线
```

老站的 `recite/` 是「大字课文 + 打卡圈」，这边的背诵单**不是它的搬运** ——
换成了下面那套方法，老站那张只解决「字大好读」，解决不了「背得慢」。

**栏目名不是目录名。** 代码在 `src/generator/chinese/<栏目>.py`，内容在
`storage/spec/chinese/<栏目>/`，两棵树靠栏目名对齐，取路径一律走
`paths.spec("chinese", "<栏目>")`（`lib/paths.py`），**别用 `Path(__file__).parent`
往下拼** —— 代码和数据不在同一棵树上。

一个栏目一个模块，`build.py` 只做分发，**每个栏目单独一层 try** —— 一个栏目的
spec 写错不该把另外两个带下水。

老站 `../chinese/` 还在线上跑（`cn.hi-ruby.com`），朗读打卡（`recite/`）
还只在那儿，要搬就去翻它和它的 README。

## 今日练习（spec/chinese/practice/`<YYYYMMDD>.txt`）

一天一份。**标对拼音是这个栏目的核心职责，也是唯一容易出错的地方**：

- 音节数必须等于字数（`麻雀=má què` → 2 格），不符时脚本报错并提示写法
- 生字比词语更需要练手，惯例 `[生字] copies=3`、`[词语] copies=2`
- `copies` / `cell` 是「排满一页 A4」的两个旋钮：装不满就加大，快溢出就调小
- 答案版格子里印楷体字给家长批改，**不进目录页**

拼音候选可以让喂数据台先给（`../../feeder/bin/feeder pinyin 潮 据 堤`，或者直接
喂生字表照片），它会把**多音字全标出来** —— 但按课文语境定音仍旧是人的活。

## 背诵单（spec/chinese/recite/`<课号>.txt`）

背诵慢多半不是记性问题，是方法：多数孩子在「重读」，而**重读几乎不产生记忆**。
这张单子把四条真起作用的做法印在纸上，家长照着走就行。

- **切块**：9 岁的工作记忆一次装 4±1 个单位，所以一段切成 4 块上下，
  一块一行。连的时候**只连相邻两块**，别每次从头 —— 从头背会让开头背了
  几十遍、结尾永远不熟（系列位置效应）。每天先从昨天卡住的那一块开始
- **提取练习**：读一遍就盖住说一遍，说不出来才看一眼。「难受」正是记忆在
  形成，看着书顺下来那种流利是假的
- **提示递减**：三轮 —— 看全文 → 只看首字 → 白纸。每块右边三个格子，
  一轮一个勾（首字脚本自动取，关键词是人给的解读）
- **间隔重复**：`plan: 1,2,4,7` 是打卡的第几天。睡前过一遍（记忆在睡眠里
  固化），第二天早上那一遍最能暴露真实水平

判定「掌握」的四条判据印在页底，**缺一条都不算**：流利（卡壳 0 次）、
准确（0 处错漏）、**中间切入**（随口报一块能接下一块，抽查点脚本自动挑）、
保持（隔 ≥1 天再过）。第三条最能识破假掌握 —— 只会顺流背的孩子从头能背，
报中间那句就接不上，说明他记的是一条声音链、不是内容。

⚠️ **原文照课本逐字抄，标点也照书** —— 这张纸是要照着背的，印错一个字
孩子就背错一个字。`make textbook` 会逐块比对（严格匹配，被旁批插断的报 `?`），
但**它抓不到漏字**（少一个字仍是顺序子串），所以定稿前还要对着书读一遍。
切块和关键词是判断，不是书上的东西。

三种课文，切法不一样：

- **白话课文**（观潮）：一段一个区块，按语义切成 4 块上下，关键词给意象
- **古诗**（8 课、27 课）：一首一个区块、**一句一块** —— 诗本来就按句背。
  关键词给意象（「残阳铺水」「横看岭 侧看峰」）
- **文言文**（12 课、23 课）：按句读切，**关键词那列给白话** ——
  文言文先懂意思才背得住，给意象没用

四个排版旋钮，动的次序也是固定的：

- `size:` 原文字号，默认 **17px**。孩子要照着这行读、再盖住说，
  **这是给九岁孩子的下限，别为了塞内容往下调** —— 塞不下先收间距、
  再考虑一段一张
- 短块（≤14 字，`INLINE_MAX`）的提示自动排到原文**右边**而不是下面。
  古诗一句 7 字、右边一大片空白，12 块摊下来省掉半页 ——
  三首诗的单子本来要两页，就是这么压回一页的
- 块 ≤6（`BLANK_MAX`）时下半页自动出**背写格**（横线用重复渐变画，
  高度自适应）。精卫填海、王戎不取道旁李都只有 4 块，原来下半页是一片白纸。
  **按块数判断、不靠 CSS 收缩** —— flex 压到 0 也还留着 border 和 padding，
  长单子会被那几毫米顶到第二页
- `copy:` 书上要求默写的那几首，页底多一条判据「默写零错字」

⚠️ 短块的内联版式**只在纸上**：`.text` 是 nowrap 的，手机上宽度不够，
提示会被挤成一字一行的竖条、还压到勾选格底下。所以 `@media screen` 窄屏
一律回到上下排 —— 纸上省页高，屏幕上纵向不缺空间。

## 抽查单（spec/chinese/check/`<课号>.txt`）

学完一课，家长照着单子问一遍，十分钟知道哪儿没记住。**一课一张，一张一页。**

- **spec 按课号命名**（`01.txt` = 第 1 课），不按日期 —— 学完哪课打哪张，
  几课混在一张上就看不出是哪课没记住
- **语文园地用 `<课号>y`，严格照课本目录排在所属单元最后一课后面**：
  `03y` 是语文园地一（第一单元末，第 3 课后）、`07y` 二、`10y` 三、`14y` 四。
  **别把园地堆到最后** —— 课本就是这个顺序，抽查顺序跟着课本走（`_order()`）。
  园地四（`14y`）现在**还没有** —— 它在书页 55，手上这份电子课本只到 53，
  没做也别编
- **两版分开印**：题面版给孩子（答案不印，动笔的题空着写，页底错题格吃掉空白），
  家长版 `<课号>-answers`（答案全印，听写横线压到 1 行）。
  **目录页每条右边挂一个「家长版」入口** —— 家长照着问的就是这一份，
  在手机上点开就能问。今日练习的答案版仍旧不列：那是批改参考，
  列出来孩子先看见答案
- **以口头题为主**（读音、背诵、复述）—— 十分钟才问得完。动笔的题超过两三项，
  就该去今日练习出一张正经的默写单，别把抽查单撑成练习单
- **`pass=` 要写得能一眼判定**：`错 ≤ 1 个`、`零错字`、`顺序说对` 可以，
  「基本掌握」不行
- **背诵题的答案写成「关键节点 → 关键节点」的链条，别抄整段原文** ——
  家长扫一眼就知道漏了哪句，原文抄上去占满一页反而不好核对
- 一课的常规块序：读准（多音字 / 易错音）→ 背诵（**书上要求的才有**）→ 听写
  （本课写字表抽几个）→ 课后题（口头）→ 词语意思，5~6 块 15~20 项正好一页十分钟。
  这一课要不要背、要不要默写，**先查教材总览**
- **字号是给孩子看的**：题面楷体 20px、块名 18px，别为了塞内容调小 —— 塞不下就删块

## 教材总览（spec/chinese/overview/`<册>.txt`）

一册一份的宏观总表：每课一行，**哪篇要背、哪首要默写一眼看到**。

- **一册一份，按册命名不按日期**（`g4a` = 四年级上册）—— 这是和别的栏目唯一
  不一样的地方（那两个是一天/一课一份）
- **行顺序严格照课本目录**：语文园地排在它所属单元最后一课后面
  （1、2、3\*、园地一、4…7\*、园地二、8、9、10、园地三、11…14\*、园地四），
  别按类型堆一起
- 背诵 / 默写两列有要求就上底色加圆点 —— **这张表的全部用处就是那个圆点**，
  扫一眼知道哪几行有活儿。`recite=待补` 印灰字、不加圆点，也不算进「要背」
- **日积月累算「要背」，但和课文背诵分开统计**，页头分别显示两个数 ——
  混着数看不出课文要背几处
- **纸上是 A4 横版**（`@page{size:A4 landscape}`，覆盖 print.css 的竖版锁，
  写法和课程表一致）。竖版时「其他要求」那列只剩 73mm ≈ 20 字一行，课后题
  原话被挤成一条窄河、一行折 5~7 行；横过来同一列有 145mm ≈ 38 字，折 2~3 行
  就完了 —— **这张表宽而不高，横版才是它的形状**
- **一单元一页**：`[分页]` 落在每个单元第一课之前，head 是单元名（印在页头
  标题后面）。页 = 单元，换页点跟着课本的结构走，**不跟着「这一页还能塞几行」
  走**；所以行高保持自然、表格不拉伸撑满（试过撑满：第五单元只有两课，
  那页被摊成两个巨大的空格子）。单元行数少的那页页底就是留白，
  那是结构留的白，不是排版没排满
- **正文是 14px（五号）、行距 1.85**，`td.other`（书上原话那一列）也一样 ——
  这张表是给孩子和家长在书桌上扫的，**这也是字号下限**，字小了就不看了。
  排不下先从别的列匀宽度给 other（行高几乎全由它折几行定），别动字号和行距。
  行距要跟着字号一起看：14px × 1.85 ≈ 26px，和小四那版 16px × 1.7 观感一样
- **列宽在 `<colgroup>` 的 `.c-*` 上，配 `table-layout:fixed`**。写在 td 上会被
  fixed 布局当成建议值忽略（踩过：other 列被均分成 38mm，八页全部溢出）；
  而 auto 布局下 `《黄鹤楼送孟浩然之广陵》李白` 这种长词会把 recite 列撑宽、
  从 other 那儿抢走十几毫米，长的课后题就多折一行
- **改完拿 `make fit URL=…` 逐页查溢出**（`tools/fit.mjs`）：哪个单元的内容高过
  一页，页脚就会被挤到下一张纸上，PDF 里多出一张只印页码的白纸 ——
  这在 HTML 源码里看不出来。第八单元那页最挤（5 行都是三行长的课后题，
  页底还要钉小结），五号字下还剩 130px 上下，改内容前后都要量
- **同一份 HTML 两用**：纸上是 A4 横版打印单，屏幕上是速查页。手机窄，所以
  表格在 `.scroll` 里横滚、摘要和小结回一栏 —— 只在 `@media screen` 里改，
  `@media print` 一个字都不动

## 三个栏目共用的

- **spec DSL 只解析骨架**（`lib/spec.py`）：文件头 `key: value`、`[区块] 抬头 key=值`、
  项行、缩进说明行。区块内容的语义各栏目自己解释 —— 练习单的「字=拼音」、
  抽查单的 `ask: 题面 | 答案`、总览的 `read=/recite=/copy=/write=` 差得太远，
  过度抽象比重复更难改
- **`|` 右边和 `key=` 的值都可以带空格**（按下一个 `key=` 切断），
  老站那条「`pass=` 必须写在属性最后」的限制在这里不存在
- **Python 里不拼标记**：标记全在 `src/templates/<栏目>/`，生成器只出算好的数和
  选好的类名。「有没有要求」「写几个字」这类判断留在 `.py` 里，模板只管摆 ●
- **改完排版一定 Read 生成的 PDF 自检**，别凭 HTML 源码想象效果。
  打印单还要在手机上量一次横向溢出（`make shot URL=… PROBE=1`）——
  `.sheet` 有 `max-width:100%`，但里面多列的表格和 `nowrap` 的长句压不动
